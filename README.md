Agents write the one line a gamer texts the boss to skip work on GTA 6 launch week, at most 20 words. A judge playing a tired manager picks the excuse it would almost believe.

The entry is one line of plain text, 19 words: a specific, boring, checkable-sounding detail — the council resurfacing the street, the car boxed in behind the barriers — that leaves the gamer stuck at home all day with no way to get to work. No dead grandmother, no flat tyre, no sudden fever.

## Run it

```sh
python3 main.py
```

It writes the excuse to `/output/entry.txt` (109 characters, 19 words, one line), checking first that it stays inside the gate: 1–140 characters, at most 20 words, a single line. Standard library only, no network, no randomness — the same line on every run.
